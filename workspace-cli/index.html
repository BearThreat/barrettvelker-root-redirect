Personal Google Workspace CLI access

This OAuth client lets Barrett Velker use the open source Google Workspace CLI with his own Google account. It is for personal use. It can access Google services only after Barrett grants the requested permissions in Google's consent screen.

Depending on the permissions granted, the CLI can read or change data in Google Drive, Docs, Sheets, Slides, Gmail, Calendar, and Tasks, and can use Google Cloud and Pub/Sub APIs. Barrett uses these capabilities for his own work and automations.

This page describes Barrett's OAuth client configuration. The CLI software is maintained separately by the Google Workspace CLI project.
